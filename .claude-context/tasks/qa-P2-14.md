## 2. Debug kontrola

**frame-ancestors + X-Frame-Options:**
`frame-ancestors 'none'` v CSP + `X-Frame-Options: DENY` — redundantni ale korektni (CSP ma precedenci v modernich prohlizecich, X-Frame-Options je fallback pro stare).

**unsafe-inline pro scripts:**
Next.js hydratace vyzaduje `unsafe-inline`. Produkcni bezpecnost zlepsena tim, ze `unsafe-eval` je odstraneno pro produkci. Budouci faze: nonce-based CSP eliminuje unsafe-inline.

**Pokryti externich sluzeb:**
- Packeta (widget.packeta.com) — scripts, styles, images, connect, frame
- Stripe (js.stripe.com, hooks.stripe.com, api.stripe.com) — scripts, frames, connect
- Plausible (plausible.io) — scripts, connect
- Sentry (*.sentry.io) — connect, images
- Cloudinary (res.cloudinary.com) — images
- Google Fonts (fonts.googleapis.com + fonts.gstatic.com) — styles, fonts

**NALEZ — CSP report endpoint status 204 s JSON body:**
Radek 22: `return NextResponse.json({ received: true }, { status: 204 })` — HTTP 204 No Content by technicke nemel mit response body. V praxi prohlizece toto ignoruji a neodeslani violations neovlivni, ale je to HTTP spec violation. Melo by byt bud `status: 200` s JSON body, nebo `new NextResponse(null, { status: 204 })`.

**report-uri vs report-to:**
`report-uri` je deprecated v moderních prohlizecich ve prospech `Reporting-API` s `report-to` direktivou. Funguje ale v legacy i modernich prohlizecich. Nizka priorita.
