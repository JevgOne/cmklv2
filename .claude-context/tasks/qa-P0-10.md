### Statická analýza

**Typy a runtime:**  
✅ `guestToken: null` pro přihlášeného uživatele — `...(null && {...})` → spread prázdného objektu → čisté  
✅ `token === order.guestToken` — přesná shoda, konstantní čas (PostgreSQL unique index)

✅ Token je 64 hex znaků (256 bit entropy) — brute force infeasible

✅ Přihlášený uživatel dostane `guestToken: null` → jeho objednávku nelze sledovat přes token (správné)
