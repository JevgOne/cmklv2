### Doporuceni fix pro quantity validaci

V `app/api/orders/[id]/returns/route.ts`, radky 65-70, pridat kontrolu:

```ts
let requestedAmount = 0;
for (const item of data.items) {
  const orderItem = order.items.find((i) => i.id === item.orderItemId)!;
  if (item.quantity > orderItem.quantity) {
    return NextResponse.json(
      { error: `Nelze vratit vice nez ${orderItem.quantity} ks polozky` },
      { status: 400 }
    );
  }
  requestedAmount += orderItem.unitPrice * item.quantity;
}
```

**Kritické bugy: 0**
**Stredni bugy: 1** (quantity overrun -- neni exploitable protoze admin schvaluje castku rucne, ale requestedAmount je nespravny)
**Blokující problémy: 0**
**Implementace pripravena k produkci: ANO** (s doporucenim opravit quantity validaci)
