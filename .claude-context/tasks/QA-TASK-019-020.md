## 1. SIMPLIFY KONTROLA

### TASK-019 — Inzertní platforma

#### ⚠️ Duplicitní pole: `wantBrokerHelp` vs `wantsBrokerHelp`
- **Soubor:** `components/web/listing-form/ListingFormWizard.tsx:59`, `lib/validators/listing.ts:53`
- **Problém:** Komponenta používá `wantBrokerHelp`, DB schema a API validator používají `wantsBrokerHelp`. API route má fallback logiku `data.wantsBrokerHelp || data.wantBrokerHelp || false` kvůli tomuto rozdílu.
- **Závažnost:** Nízká (funguje díky fallbacku), ale zbytečná komplexnost
- **Doporučení:** Sjednotit na `wantsBrokerHelp` v celém kódu (component → form data → API)

#### ⚠️ `inzerce/katalog/page.tsx` — statická stránka místo redirect
- **Soubor:** `app/(web)/inzerce/katalog/page.tsx`
- **Problém:** Stránka je statická HTML s odkazem na `/nabidka` místo server-side redirect (`redirect('/nabidka')`). Toto je SEO problém — crawlery si zaindexují stránku s nízkým obsahem.
- **Závažnost:** Střední (SEO)
- **Doporučení:** Nahradit za `import { redirect } from 'next/navigation'; export default function() { redirect('/nabidka'); }`
