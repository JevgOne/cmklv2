### 4. BUGS D16

#### ⚠️ BUG-1 — `totalPrice` pro non-admin vynechává shipping

**Soubor:** `app/api/partner/orders/[id]/pdf/route.ts:84`

**Kód:**
```typescript
totalPrice: isAdmin ? order.totalPrice : itemsTotal + (isAdmin ? order.shippingPrice : 0),
```

**Problém:** Vnější ternář `isAdmin ? ... : itemsTotal + (isAdmin ? ... : 0)` — ve větvi `!isAdmin` se inner ternář `(isAdmin ? order.shippingPrice : 0)` vždy vyhodnotí jako `0`. Výsledek: non-admin PDF total = `itemsTotal` (bez dopravy).

**Dopad v PDF:**
```
Polozky:  500 Kč
Doprava:  100 Kč        ← zobrazeno z shippingPrice
Celkem:   500 Kč        ← NESPRÁVNĚ chybí doprava (mělo by být 600 Kč)
```

**Původ:** Bug přítomen v plánu (`plan-D16-pdf-partner-orders.md` §1.2 line 372) — implementátor kód zkopíroval verbatim.

**Fix:**
```typescript
// Místo:
totalPrice: isAdmin ? order.totalPrice : itemsTotal + (isAdmin ? order.shippingPrice : 0),
// Správně:
totalPrice: isAdmin ? order.totalPrice : itemsTotal + order.shippingPrice,
```

**Závažnost:** Střední — PDF generuje a stahuje se, ale zobrazuje nesprávný celkový součet pro partnery/dodavatele.
