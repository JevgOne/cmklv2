## 1. Simplify kontrola

### Focus-visible (globals.css, radky 146-157)

- `*:focus-visible { outline: 2px solid var(--orange-500); outline-offset: 2px; }` -- globalni focus ring
- `input:focus-visible, select:focus-visible, textarea:focus-visible { outline: none; }` -- reset pro form prvky s vlastnim focus stylem
- Overeno: Input/Select/Textarea maji `focus:border-orange-500 focus:shadow-[...]` jako nahradni ring

### Skip-to-content (app/(web)/layout.tsx, radky 53-58)

- `<a href="#main-content" className="sr-only focus:not-sr-only focus:fixed focus:top-4 focus:left-4 focus:z-[300] ...">Prejit na obsah</a>`
- `<main id="main-content" ...>` na radku 60
- Spravne: sr-only skryty, pri focus se zobrazi jako fixni tlacitko

### Modal (components/ui/Modal.tsx, 103 radku)

- `role="dialog"` + `aria-modal="true"` + `aria-labelledby={title ? titleId : undefined}`
- Zaviraci tlacitko: `aria-label="Zavrit"`
- Focus trap: `FOCUSABLE` selector, Tab/Shift+Tab cycling (radky 30-43)
- Auto-focus na prvni focusable element pri otevreni (radek 51-53)
- Focus return: `triggerRef.current?.focus()` v cleanup (radek 58)
- Escape: `handleEscape` callback (radky 23-28)
- Body scroll lock: `overflow: "hidden"` (radek 50)
- Backdrop click to close: `e.target === e.currentTarget` (radky 68-70)

### Tabs (components/ui/Tabs.tsx, 83 radku)

- `role="tablist"` na kontejneru (radek 58)
- `role="tab"` na kazdem tlacitku (radek 68)
- `aria-selected={isActive}` (radek 69)
- `tabIndex={isActive ? 0 : -1}` -- roving tabindex pattern (radek 70)
- Keyboard navigace: ArrowLeft/Right (cyklicka), Home, End (radky 34-48)
- Focus management: `tabRefs.current.get(newTab.value)?.focus()` (radek 51)

### Input/Select/Textarea (3 soubory)

Vsechny 3 shodne:
- `const errorId = error ? \`${id}-error\` : undefined`
- `aria-invalid={error ? true : undefined}`
- `aria-describedby={errorId}`
- `<span id={errorId} role="alert" className="text-[13px] text-error-500">{error}</span>`
- Screenreader precte error message pri focus na input

### LiveRegion (components/ui/LiveRegion.tsx, NOVY)

- `role={assertive ? "alert" : "status"}`
- `aria-live={assertive ? "assertive" : "polite"}`
- `className="sr-only"` -- vizualne skryto, jen pro screenreadery

## 2. Debug kontrola

### Staticka analyza

**Modal:**
- `titleId = "modal-title"` je hardcoded -- pokud by bylo vice modalu soucasne, doslo by ke kolizi ID. V praxi se typicky zobrazuje jen jeden modal, takze LOW riziko.
- `typeof document === "undefined"` check na radku 101 je spravne pro SSR guard, ale stoji AZ za `if (!open) return null` -- je bezpecne protoze `useEffect` se nespusti na serveru.

**Tabs:**
- `handleKeyDown` closure zachycuje `handleChange` pres uzavreni (ne pres deps) -- bezpecne, protoze `handleChange` je stabilni referenci diky tomu ze `isControlled` a `onTabChange` se nemeni casto.

**Focus-visible:**
- `outline: 2px solid var(--orange-500)` -- pouziva CSS promennou, konzistentni s design systemem. Na tmavem pozadi bude videt dobre (orange na tmave).

**Kontrast:**
- CookieConsent link opraven na `text-orange-700` (5.9:1 kontrast)
- Zbyva ~15 vyskytu `text-orange-500` v kodu, ale jsou to:
  - `hover:text-orange-500` stavy (ne staticke)
  - SVG ikony v navbaru (dekorativni, ne text)
  - Brand highlight ("CarMakler" span) -- large/bold
  - Admin stranky (interni)
  - Star ratings (ikony, ne text)
  - Tyto NEJSOU WCAG blocker, ale zbyva prostor pro zlepseni
