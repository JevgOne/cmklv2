## Nalezene problemy

### MINOR: Duplicitni MAX_FILE_SIZE (documents/route.ts + lib/cloudinary.ts)

**Soubory:** `lib/cloudinary.ts` radek 10, `app/api/onboarding/documents/route.ts` radek 8

**Popis:** `MAX_FILE_SIZE = 10 * 1024 * 1024` je definovano na obou mistech. Documents route kontroluje velikost pred volanim `uploadToCloudinary` (radek 47), a `uploadToCloudinary` ji kontroluje znovu interně (radek 36). Dvojita validace neni chyba, ale pri budouci zmene limitu by se snadno zapomnělo na jedno z mist.

**Doporuceni:** Exportovat `MAX_FILE_SIZE` z `lib/cloudinary.ts` a pouzit v `documents/route.ts`:
```ts
import { uploadToCloudinary, MAX_FILE_SIZE } from "@/lib/cloudinary";
```

### MINOR: Chybejici file type validace pro avatar (profile/route.ts)

**Soubor:** `app/api/onboarding/profile/route.ts`, radky 53-62

**Popis:** Documents route validuje typ souboru proti `ALLOWED_TYPES` (jpeg, png, webp, pdf) pred uploadem (radek 53-58). Profile route zadnou typovou validaci neprovadi -- photo se posila primo na Cloudinary. Uzivatel by mohl uploadovat PDF, SVG, nebo nevalidni soubor jako "avatar".

**Dopad:** Nizky -- Cloudinary `auto/upload` endpoint zvladne vetšinu typu a vrati korektni URL. Ale avatar by mel byt jen obrazek (ne PDF).

**Doporuceni:** Pridat validaci:
```ts
const AVATAR_TYPES = ["image/jpeg", "image/png", "image/webp"];
if (photo && !AVATAR_TYPES.includes(photo.type)) {
  return NextResponse.json({ error: "Fotka musi byt JPG, PNG nebo WebP" }, { status: 400 });
}
```

### MINOR: Chybejici MAX_FILE_SIZE validace pro avatar (profile/route.ts)

**Soubor:** `app/api/onboarding/profile/route.ts`, radky 55-61

**Popis:** Pokud uzivatel uploaduje 50 MB fotku, `uploadToCloudinary` vyhodi error ktery se chyti v try/catch (radek 58). Vysledek: avatar se tiše preskoci, uzivatel nedostane zpetnou vazbu. Na rozdil od documents route, ktera vraci HTTP 400 s jasnou chybovou hlaskou.

**Dopad:** Nizky -- uzivatel jen nebude mit avatar. Ale UX je matouci (nahral jsem fotku a nic se nestalo).

**Doporuceni:** Pridat explicitni kontrolu velikosti pred uploadem:
```ts
if (photo && photo.size > MAX_FILE_SIZE) {
  return NextResponse.json({ error: "Fotka je prilis velka (max 10 MB)" }, { status: 400 });
}
```

### INFO: Dlouhy radek v lib/analytics.ts

**Soubor:** `lib/analytics.ts`, radky 8-9

**Popis:** Typ `window.plausible` je cast dvakrat inline na jednom radku. Citelnost by se zlepila deklaraci typu.
