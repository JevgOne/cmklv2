## §2 — BLOCKER-1: PhotoUpload — chybějící upload_preset

**Soubor:** `components/partner/PhotoUpload.tsx` L24-26

```typescript
const formData = new FormData();
formData.append("file", file);
const res = await fetch("/api/upload", { method: "POST", body: formData });
```

**API `/api/upload` route.ts L44:**
```typescript
if (!preset || !PRESETS[preset]) {
  return NextResponse.json(
    { error: `Neplatny upload_preset. Povolene: ${Object.keys(PRESETS).join(", ")}` },
    { status: 400 }
  );
}
```

**Dostupné presety:** `vehicles, listings, parts, invoices, contracts, damages`

**Dopad:** Každý pokus o upload fotografie vozidla nebo dílu přes `PhotoUpload` vrátí `400 Bad Request`. Vozidla a díly nelze fotit — klíčová funkce C5 je **100% nefunkční** v produkci.

**Požadovaná oprava:**
- PhotoUpload by měl přijmout prop `preset: string` (nebo `uploadPreset: string`)
- vehicles/new a vehicles/[id] předají `preset="vehicles"`
- parts/new a parts/[id] předají `preset="parts"`
- `formData.append("upload_preset", preset)` uvnitř handleUpload

**Závažnost: BLOCKER** ❌

**Závažnost: BLOCKER** ❌
