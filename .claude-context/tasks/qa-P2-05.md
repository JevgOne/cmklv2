  - Odstranuje specialni znaky, ponechava ceske diakritiky

`smartSearch(query, { limit, offset, type })`:

## 2. Debug kontrola

**SQL injection:** `$queryRawUnsafe` + parametry `$1,$2,$3` — spravne, ne string interpolace

**tsQuery prefix matching:** `w:*` umoznuje hledat prefix, `to_tsquery('simple', 'brak:*')` najde "brzdovy", "brzdy" atd.

**sanitizeQuery edge case:** prazdny query po filtraci vraci `""`, `smartSearch` vraci prazdne vysledky

**Poznamka — Vehicle ve smartSearch:**
`smartSearch` prohledava Part a Listing, ale ne Vehicle. Plan obsahuje Vehicle search. searchVector pro Vehicle existuje (schema + migrace + trigger), ale API ho neexponuje. Prijatelne — `/nabidka` katalog ma vlastni filtry.

**Plan vs impl — `$queryRaw` vs `$queryRawUnsafe`:**
Plan pouziva `$queryRaw` s tagged template literals (Prisma auto-escaping). Implementace pouziva `$queryRawUnsafe` s parametrizovanymi dotazy ($1 syntax). Oba pristupy jsou bezpecne — `$queryRawUnsafe` s pozicnimi parametry funguje stejne jako `pg` parametrized queries.

**Plan vs impl — COD fee:**
Plan zminuje COD 49 Kc (v P2-20 kontextu). Implementace pouziva 39 Kc. Toto neni P2-05 issue, ale zasahuje shipping logiku.
