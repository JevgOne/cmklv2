### 1.2 Automotive-specifické SEO taktiky

**Schema markup pro automotive:**
- `AutoDealer` — základ pro business entity (name, location, hours, contact)
- `Car` (subtyp `Vehicle`) — make, model, year, price, mileage, condition, VIN
- `Product` + `Offer` — cena, dostupnost, stav (used/new), měna
- `AggregateRating` — MUSÍ reflektovat reálné, ověřitelné recenze
- `EngineSpecification` — displacement, power, fuelType, torque
- **Google zrušil Vehicle Listing SD (červen 2025)** — ale obecný `Vehicle`/`Car` schema funguje dál

**Aftermarket/Parts specifika:**
- Product schema MUSÍ obsahovat fitment data, part numbers, kompatibilitu
- FAQPage schema na recall tools a service FAQ — zvyšuje CTR
- Kategorie strukturovat dle search intentu: part-specific, symptom-based, category-level
- OEM + aftermarket part number cross-reference v product pages
- Canonical tags na filtrované stránky (zabránit duplicate content)

**Local SEO pro automotive:**
- Google Business Profile = #1 priorita pro local visibility
- NAP konzistence na 100% (web, GBP, Firmy.cz, Mapy.cz)
- Hyper-local landing pages per město s unikátním contentem
- Review management — 70% kupujících aut potvrzuje vliv recenzí
- Local Pack zachytává 60% in-person návštěv

## 3. LLMS.TXT — Specifikace 2026

### 3.1 Stav adopce

| Metrika | Hodnota |
|---------|---------|
| Webů s llms.txt | 844 000+ |
| Major adopters | Anthropic, Cloudflare, Stripe, Vercel |
| AI firmy oficiálně supportující | Žádná (proposed standard) |
| Anthropic vlastní llms.txt | Ano (na anthropic.com) |

**Realita:** llms.txt je "proposed standard" — žádná AI firma oficálně nepotvrdila, že ho čte. ALE je low-effort a potenciálně užitečný pro agentické nástroje (Cursor, Claude Code, Copilot).

### 3.2 Specifikace formátu

```markdown
# {H1 — název projektu/webu}           ← POVINNÉ

> {Blockquote — stručný popis}          ← VOLITELNÉ

{Body — detailní text}                  ← VOLITELNÉ

## {H2 sekce — kategorie odkazů}        ← VOLITELNÉ
- [Name](URL): Description              ← Seznam s hyperlinky
- [Name](URL): Description

## Optional                              ← Speciální sekce pro sekundární info
- [Name](URL): Description
```

**Pravidla:**
- Soubor MUSÍ být na root: `/llms.txt`
- Formát: Markdown (ne XML/JSON)
- Markdown hyperlinky POVINNÉ v seznamech
- Volitelný `:` + popis za odkazem
- Sekce "Optional" = sekundární info (může být přeskočena pro kratší kontext)

### 3.3 Companion soubory

| Soubor | Účel |
|--------|------|
| `llms.txt` | Hlavní kurated mapa (stručná) |
| `llms-full.txt` | Rozšířená verze s detaily |
| `*.md` verze stránek | LLM-friendly content mirrors (URL + `.md`) |
| `llms-ctx.txt` | Generované nástrojem `llms_txt2ctx` |

### 3.4 Doporučení pro CarMakléř

Vytvořit `/public/llms.txt` s:
- H1: "CarMakléř"
- Blockquote: 2 věty o platformě
- 5-6 H2 sekcí: Hlavní stránky, Služby, Díly, Marketplace, O nás, Blog
- 20-30 odkazů s popisy
- "Optional" sekce: právní stránky, API docs

## 4. NEXT.JS 15/16 SEO — Aktuální best practices

### 4.1 Co se změnilo

| Oblast | 2024 | 2025-2026 |
|--------|------|-----------|
| Metadata | Metadata API (App Router) | Stále standard, `next-seo` deprecated pro App Router |
| Structured data | JSON-LD v Server Components | Stále standard, render server-side |
| Sitemap | `app/sitemap.ts` | + `generateSitemaps()` pro velké inventáře |
| Robots | `app/robots.ts` | + AI crawler konfigurace |
| Images | `next/image` | + `priority` prop, explicit `sizes` |
| Fonts | `next/font/google` | `display: swap` standard |
| CWV metrika | FID → INP | INP je nový standard od března 2024 |
| Viewport | `metadata.viewport` | Separátní `viewport` export |
| Rendering | SSG default | SSG + ISR + streaming (Suspense) |

### 4.2 Klíčové best practices

1. **Metadata API hierarchicky:** Root layout → nested layout → page override
2. **generateMetadata()** pro dynamické stránky (vehicles, parts, blog)
3. **JSON-LD jako Server Component** — `<script type="application/ld+json">` bez client JS
4. **ISR s revalidate** pro vehicle listings, blog (ne SSR pro každý request)
5. **Streaming s Suspense** pro data-heavy sekce (výpisy vozidel, katalog dílů)
6. **`next/image` s priority** na hero images above-the-fold
7. **Canonical URLs** přes `alternates` v metadata (ne ruční `<link>`)
8. **Separate `viewport` export** (Next.js 15+ requirement)

### 4.3 Co aplikovat na CarMakléř

| # | Akce | Status | Priorita |

| 1 | Metadata API na VŠECHNY stránky | 24% → 100% | CRITICAL |

| 3 | ISR na vehicle/part listings | ❓ Ověřit | MEDIUM |
| 4 | Suspense boundaries na katalogy | ❓ Ověřit | MEDIUM |
