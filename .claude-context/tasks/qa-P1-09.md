  id        String   @id @default(cuid())

### POST /api/auth/forgot-password/route.ts

✅ Schéma: `z.object({ email: z.string().email() })` — správně, min validace

✅ `expiresAt = now + 1h` ✅  
✅ `sendEmail()` z `lib/resend.ts` s HTML šablonou Carmakler branding ✅  
✅ Reset URL: `${NEXT_PUBLIC_APP_URL || "https://www.carmakler.cz"}/reset-hesla/${token}` — fallback na produkční URL ✅

### POST /api/auth/reset-password/route.ts

✅ Schéma: `token: z.string().min(32)`, `password: z.string().min(8)` ✅  
✅ `findUnique({ where: { token } })` — využívá @unique index  
✅ Kontroly v pořadí: not found → 400, used → 400, expired (`expiresAt < new Date()`) → 400 ✅  
✅ User lookup po validaci tokenu ✅  
✅ `bcrypt.hash(password, 12)` — 12 rounds ✅
